## 📊 Дашборд

### Статистика
При входе в панель администратора вы увидите:

1. **Всего товаров** - общее количество товаров в каталоге
2. **Общая стоимость** - суммарная стоимость всех товаров на складе
3. **Мало на складе** - количество товаров с остатком < 10 шт
4. **Нет в наличии** - количество товаров с нулевым остатком

### Предупреждения
- Если есть товары с низким остатком, появится желтое предупреждение
- Список товаров, которые заканчиваются (первые 5)
- Кнопка "Пополнить" для быстрого редактирования

### Обзор по категориям
- Количество товаров в каждой категории
- Общая стоимость товаров по категориям

## 🛠️ Управление товарами

### Просмотр товаров
1. Перейдите на вкладку **"Товары"**
2. Увидите таблицу со всеми товарами:
   - Изображение
   - Название и бренд
   - Категория
   - Цена (редактируемая)
   - Остатки (редактируемые)
   - Действия (редактировать/удалить)

### Поиск и фильтрация
- **Поиск**: Введите название или бренд в поле поиска
- **Фильтр**: Выберите категорию из выпадающего списка
- Счетчик показывает количество найденных товаров

### Быстрое редактирование

#### Изменение цены:
1. Кликните на поле с ценой в таблице
2. Введите новую цену
3. Изменения сохраняются автоматически

#### Изменение остатков:
1. Кликните на поле с остатками
2. Введите новое количество
3. Изменения сохраняются автоматически

**Цветовая индикация:**
- 🟢 Зеленый: > 10 шт (хорошо)
- 🟡 Желтый: 1-10 шт (мало)
- 🔴 Красный: 0 шт (нет в наличии)

### Добавление товара
1. Нажмите кнопку **"➕ Добавить товар"**
2. Заполните полную форму товара:

#### Основная информация:
   - **Название** - полное название товара (обязательно)
     - Пример: "Шина грузовая Michelin X Multi Z 315/80R22.5"
   - **Бренд** - производитель товара
     - Пример: "Michelin", "Bosch", "Volvo"
   - **Описание** - детальное описание товара (многострочное)
     - Укажите характеристики, преимущества, особенности

#### Ценообразование и наличие:
   - **Цена (сум)** - цена в узбекских сумах
     - Только числа, без пробелов
   - **Наличие (шт)** - количество на складе
     - Можно указать 0 (товар будет виден, но недоступен для покупки)

#### Классификация:
   - **Категория** - выберите категорию из выпадающего списка
     - Если нужной категории нет, создайте её во вкладке "Категории"
   - **Артикул** - уникальный код товара
     - Пример: "XMZ-315-80-22.5", "F026402067"

#### Изображение:
   - **URL изображения** - прямая ссылка на изображение товара
     - Формат: https://example.com/image.jpg
     - Рекомендуемый размер: 600x600px
     - Поддерживаемые форматы: JPG, PNG, WebP
   - **Предпросмотр** - автоматически отображается при вводе URL
     - Проверьте, что изображение загружается корректно

#### Дополнительная информация:
   - **Совместимость** - марки грузовиков (через запятую)
     - Пример: "Mercedes, Volvo, Scania, MAN"
     - Будет отображаться на детальной странице товара
   - **Хит продаж** - чекбокс для выделения товара
     - ⭐ Товар будет помечен меткой "Хит продаж"
     - Отображается на главной странице в разделе рекомендаций

#### Сводка товара:
   - Автоматически отображается внизу формы
   - Показывает все введенные данные
   - Цветовая индикация остатков:
     - 🟢 Зеленый: > 10 шт
     - 🟡 Желтый: 1-10 шт
     - 🔴 Красный: 0 шт

3. Проверьте сводку товара
4. Нажмите **"➕ Добавить товар"**

**Примечания:**
- Все поля можно заполнить сразу или частично
- Товар можно добавить с количеством 0 (без наличия)
- Изображение обязательно для корректного отображения
- Совместимость помогает пользователям найти подходящий товар

### Редактирование товара
1. Нажмите иконку карандаша (✏️) рядом с товаром
2. Измените нужные поля
3. Нажмите **"Сохранить"**

### Удаление товара
1. Нажмите иконку корзины (🗑️) рядом с товаром
2. Товар будет удален без подтверждения (будьте осторожны!)

## 📁 Управление категориями

### Просмотр категорий
1. Перейдите на вкладку **"Категории"**
2. Увидите карточки всех категорий с:
   - Изображением
   - Названием
   - Описанием
   - Кнопками действий

### Добавление категории
1. Нажмите **"Добавить категорию"**
2. Заполните форму:
   - **Название** - название категории
   - **Описание** - краткое описание
   - **Slug (URL)** - автоматически из названия или вручную
   - **URL изображения** - ссылка на изображение
3. Нажмите **"Добавить"**

### Редактирование категории
1. Нажмите **"Редактировать"** на карточке категории
2. Измените нужные поля
3. Нажмите **"Сохранить"**

### Удаление категории
1. Нажмите иконку корзины на карточке
2. Категория будет удалена

**⚠️ Внимание:** Удаление категории не удаляет товары из неё!

## 💡 Советы и рекомендации

### Управление остатками
- Регулярно проверяйте дашборд на предупреждения
- Используйте быстрое редактирование для обновления остатков
- Товары с нулевым остатком видны пользователям, но недоступны для покупки

### Ценообразование
- Изменяйте цены прямо в таблице для скорости
- Для массового изменения используйте полное редактирование

### Категории
- Используйте качественные изображения (рекомендуется 800x600px)
- Пишите понятные описания для пользователей
- Slug должен быть уникальным (латиница, дефисы)

### Изображения товаров
- Используйте ссылки на изображения (например, с Unsplash, Imgur)
- Рекомендуемый размер: 600x600px
- Формат: JPG или PNG

### Безопасность
- Не делитесь учетными данными администратора
- Регулярно проверяйте каталог на ошибки
- Делайте резервные копии данных

## 🆘 Часто задаваемые вопросы

**Q: Как добавить товар без наличия?**
A: При добавлении товара укажите количество 0 в поле "Наличие (шт)"

**Q: Можно ли изменить цену нескольких товаров сразу?**
A: Пока нет, но вы можете быстро изменить цены прямо в таблице

**Q: Что произойдет при удалении категории?**
A: Категория удалится, но товары останутся (будут без категории)

**Q: Как загрузить изображение?**
A: Загрузите изображение на сервис (Imgur, Cloudinary) и вставьте ссылку

**Q: Сохраняются ли изменения автоматически?**
A: Да, при быстром редактировании (цена, остатки). Нет - в модальных окнах (нужно нажать "Сохранить")
