# 🚀 Быстрый старт TruckParts

## Установка и запуск

### 1. Установите зависимости:
```bash
npm install
```

### 2. Запустите проект:
```bash
npm run dev
```

### 3. Откройте в браузере:
```
http://localhost:3000
```

## 🎯 Навигация

- **/** - Главная страница
- **/categories** - Все категории
- **/products** - Каталог товаров
- **/favorites** - Избранное
- **/cart** - Корзина
- **/profile** - Профиль пользователя
- **/login** - Вход в систему
- **/admin** - Панель администратора

## 💡 Советы

1. **Темная тема:** Нажмите на иконку луны/солнца в шапке
2. **Поиск:** Используйте строку поиска в шапке сайта
3. **Фильтры:** На странице товаров доступны фильтры слева
4. **Избранное:** Нажмите на сердечко на карточке товара
5. **Корзина:** Нажмите на кнопку "В корзину" на карточке товара

## 🛠️ Разработка

### Структура файлов:
```
src/
├── components/     # Компоненты
├── pages/         # Страницы
├── store/         # Zustand store
├── types/         # TypeScript типы
└── data/          # Моковые данные
```

### Добавление нового товара (через админ-панель):
1. Войдите как администратор
2. Перейдите в `/admin`
3. Вкладка "Товары" → "Добавить товар"
4. Заполните форму и сохраните

### Добавление новой категории:
1. Войдите как администратор
2. Перейдите в `/admin`
3. Вкладка "Категории" → "Добавить категорию"
4. Заполните форму и сохраните

## 📦 Сборка для продакшена
