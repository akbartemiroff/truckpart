# 🚛 TruckParts - E-Commerce платформа для запчастей грузовых машин

Полнофункциональная веб-платформа для продажи запчастей грузовых автомобилей и фур, построенная на React + TypeScript + Vite + TailwindCSS.

## 🎯 Особенности

### Для пользователей:
- 🛍️ Просмотр товаров с фильтрацией и сортировкой
- 📄 Детальная страница товара с полным описанием
- ⭐ Отзывы пользователей с рейтингами
- ❤️ Добавление товаров в избранное
- 🛒 Корзина покупок с расчетом суммы
- 📦 Оформление заказов
- 👤 Личный профиль с историей заказов
- 🔍 Поиск товаров по названию, бренду, описанию
- 🔙 Навигация с кнопкой "Назад"

### Для администраторов:
- 📊 **Дашборд с аналитикой**:
  - Статистика товаров в реальном времени
  - Общая стоимость товаров на складе
  - Предупреждения о низких остатках
  - Обзор товаров по категориям
- 🛠️ **Управление товарами**:
  - Добавление новых товаров с полной информацией
  - Быстрое редактирование цен прямо в таблице
  - Изменение остатков без модального окна
  - Поиск по названию и бренду
  - Фильтрация по категориям
  - Цветовая индикация остатков (зеленый/желтый/красный)
- 📁 **Управление категориями**:
  - Добавление, редактирование, удаление категорий
  - Загрузка изображений для категорий
  - Визуальное представление карточками
- ⚙️ **Настройки сайта**:
  - Название, email, телефон
  - Конфигурация платформы

### Дополнительно:
- 🌓 Темная/светлая тема
- 📱 Адаптивный дизайн (desktop и mobile)
- ✨ Плавные анимации с Framer Motion
- 🎨 Современный минималистичный дизайн
- 💾 Сохранение состояния в localStorage

## 📦 Основные компоненты

### ProductCard
Карточка товара с изображением, названием, ценой, кнопками "В корзину" и "В избранное". При клике открывается детальная страница товара.

### ProductDetailPage
Детальная страница товара с:
- Галереей изображений
- Полным описанием и характеристиками
- Системой рейтингов (5 звезд)
- Отзывами пользователей
- Информацией о совместимости
- Выбором количества
- Кнопками добавления в корзину и избранное

### CategoryCard
Карточка категории с изображением и описанием, переход к товарам категории.

### Header
Навигация с поиском, иконками корзины, избранного, профиля, переключателем темы.

### Footer
Контактная информация, ссылки на категории, социальные сети.

### Modal
Универсальное модальное окно для форм и уведомлений.

### Button
Кнопка с вариантами: primary, secondary, outline, danger.

## 🔄 Управление состоянием

Приложение использует **Zustand** для управления глобальным состоянием:

- **Аутентификация:** user, login, logout
- **Корзина:** cart, addToCart, removeFromCart, updateQuantity
- **Избранное:** favorites, addToFavorites, removeFromFavorites
- **Товары:** products, addProduct, updateProduct, deleteProduct
- **Категории:** categories, addCategory, updateCategory, deleteCategory
- **Заказы:** orders, addOrder
- **Тема:** theme, toggleTheme

Состояние сохраняется в localStorage с помощью middleware `persist`.
